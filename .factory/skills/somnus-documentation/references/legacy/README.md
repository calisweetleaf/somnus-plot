# Legacy Pattern Libraries — Superseded

These files preserve earlier experiments in Markdown layout, README structure, and visual presentation. They remain useful for understanding how the documentation system developed and for locating historical patterns that may still serve a specific project.

They are **superseded guidance**. For current work, follow the repository's established public-documentation style first, then the current `SKILL.md` and `references/design-schema.md`. Consult these legacy libraries only when the user requests them or when a historical pattern is specifically relevant. Their palettes, terminal frames, badges, and layout devices are not defaults for new documentation.

The source files are retained unchanged so their original examples and context remain intact.

## Next state
