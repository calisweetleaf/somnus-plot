# BRAINSTORM.md — Idea Flag & Context Router

**Purpose:** This file serves as a contextual idea flag. When ideas, future questions, tangential thoughts, or context shifts emerge during work, they get routed here for later evaluation rather than derailing the current task.

---

## How This File Works

This is NOT a working document for the current task — it's a **flag/routing surface** for:

1. **Tangential ideas** that emerge mid-work but aren't immediately relevant
2. **Future questions** that should be revisited after current work completes
3. **Context shifts** — when user input drifts from the original task
4. **Open questions** — things to think through before committing to implementation
5. **Reference notes** — things learned that might inform future decisions

---

## Flag Categories

### Tangential Ideas (T)

Ideas that came up during work but aren't part of the current scope.

**Format:** `T-YYYY-MM-DD: [brief description] → [where it came from]`

### Future Questions (FQ)

Questions raised that need answering before next session.

**Format:** `FQ-YYYY-MM-DD: [question] → [why it matters]`

### Context Shifts (CS)

When user input shifts context mid-task — flag it here.

**Format:** `CS-YYYY-MM-DD: [original context] → [new context] → [flagged by]`

### Open Thoughts (OT)

Unresolved thoughts, half-formed ideas, or things needing more thinking.

**Format:** `OT-YYYY-MM-DD: [thought] → [uncertainty]`

### Reference Notes (RN)

Things learned during work that might inform future decisions.

**Format:** `RN-YYYY-MM-DD: [insight] → [implication]`

---

## Flagging Protocol

When you encounter something that should be flagged:

1. **Do NOT act on it immediately** unless it's critical to the current task
2. **Append to the appropriate category** below with timestamp
3. **Continue the current task** without disruption
4. **At session end**, review flags — some may be actionable next session
